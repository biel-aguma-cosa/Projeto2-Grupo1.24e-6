# Atividade Avaliativa Prática 

**Curso:** Programador Back-End Python  
**Unidade Curricular:** Desenvolvimento Web com Django  
**Tema:** Projeto 2 - Agenda de Consultas  

### Situação de Aprendizagem 

A Clínica Saúde Viva atende diariamente dezenas de pacientes em consultas médicas e odontológicas. Atualmente, o agendamento é realizado manualmente em uma agenda física, o que tem causado conflitos de horários, dificuldades para localizar consultas e falta de controle sobre atendimentos realizados e cancelados. 

Com o objetivo de modernizar seus processos, a clínica decidiu contratar uma empresa de desenvolvimento de software para criar um sistema web que permita o cadastro e gerenciamento das consultas. 

Sua equipe foi contratada para desenvolver a primeira versão da aplicação utilizando Python, Django e SQLite.

### Desafio 

Desenvolver um sistema web denominado Agenda de Consultas, permitindo que os funcionários da clínica possam cadastrar, consultar, editar e excluir consultas de maneira simples e organizada. 

O sistema deverá utilizar o Django Admin para administração dos dados e possuir uma interface amigável desenvolvida com Bootstrap 5.

### Ao concluir esta atividade o estudante deverá demonstrar que é capaz de: 
- Configurar um projeto Django. 
- Desenvolver aplicações utilizando Django. 
- Modelar banco de dados com ORM. 
- Utilizar SQLite. 
- Desenvolver CRUD completo. 
- Utilizar Django Admin. 
- Criar Templates reutilizáveis. 
- Organizar URLs e Views. 
- Aplicar Bootstrap na construção da interface. 
- Utilizar boas práticas de organização do projeto. 

### Recursos Disponíveis 
- Python 3.x 
- Django 5.x 
- SQLite 
- Visual Studio Code 
- Bootstrap 5 
- Navegador Web 

### O estudante deverá entregar: 
 
- Projeto Django funcionando. 
- Código-fonte organizado. 
- Banco SQLite criado. 
- Interface funcional. 
- Pelo menos 10 consultas cadastradas. 

### Evidências Esperadas 

- O uso integrado dos principais recursos do Django, incluindo Modelos, ORM, Views, Templates, URLs, Formulários, Django Admin e SQLite.  
- Interface intuitiva, organizada e responsiva, permitindo o gerenciamento eficiente das consultas da clínica.
